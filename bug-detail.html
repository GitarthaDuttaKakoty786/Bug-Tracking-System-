Login button unresponsive on Safari

Critical Open
Reported By

Assigned To
A. Sharma
Reported On
02 Jul 2026
Sprint
Sprint 14

Description

The login button does not respond to clicks when using Safari on macOS. The page does not show any error, and the network tab shows no request being sent. The issue does not occur on Chrome or Firefox.

Steps to Reproduce

  1. Open the application in Safari on macOS.
  2. Go to the login page.
  3. Enter valid credentials.
  4. Click the "Login" button.

Expected vs Actual

Expected: User is logged in and redirected to the dashboard.
Actual: Nothing happens. The button shows a hover state but no click event fires.
